# Hero Management Module – AI Development Prompt

Build a **fully dynamic Hero Management module** for my CMS with a modern, enterprise-level design. The entire Hero section must be configurable from the admin panel without requiring any code changes.

## Objective

Create a Hero Slider Management system that allows administrators to create, edit, reorder, schedule, and publish multiple hero slides. The frontend should automatically render the active slides with smooth animations and responsive layouts.

---

## Hero Slider Features

* Add, Edit, Delete Hero Slides
* Enable/Disable individual slides
* Drag & Drop slide ordering
* Duplicate existing slide
* Auto-play slider
* Infinite loop
* Previous / Next navigation
* Pagination dots
* Keyboard navigation
* Touch/Swipe support for mobile
* Pause on hover
* Configurable autoplay speed
* Preview before publishing

---
